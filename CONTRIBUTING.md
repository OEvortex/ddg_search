# Contributing to ddg_search

Thanks for helping improve ddg_search — the DuckDuckGo MCP server! 🦆

## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/ddg_search.git
cd ddg_search
npm install
npm run dev
```

## Guidelines
- Open an issue before starting significant work
- Keep PRs focused on a single change
- Test with local MCP client before submitting
- Use clear commit messages

## Structure
```
ddg_search/
├── src/           # Server source
├── test/          # Tests
└── docs/          # Docs & examples
```

Need help? Open an issue!
